# Cover Viewer Proportions

## Intent

Recompose the default mobile Cover profile into a deliberate identity page: the person and their professional information should lead the first screen, followed by Save Contact and the first available link.

## Chosen approach

Keep the existing Cover renderer and full-bleed background. On mobile, scope a compact upper-third composition to the default Editorial Left variant only: a controlled gap after the IQ mark, then portrait/name, concise supporting text, Save Contact, and the start of links. Do not use a generic rule that changes Centered Hero or Bottom Sheet profiles.

## Constraints

- No changes to profile content, contact behavior, links, desktop presentation, or non-Cover templates.
- Keep portrait, title, tagline, bio, location, Save Contact and link tap targets legible.
- Existing custom Cover variants retain their selected composition.

## Success

For a normal two-line name on a typical iPhone, the opening viewport reads as a composed profile page rather than a lower-third poster: Save Contact and the beginning of the first link are visible without scrolling.
